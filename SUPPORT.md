# Support

## Where to ask

| You need | Go to |
|---|---|
| Help installing or running the CLI | Open an issue in this repository |
| A correction to this documentation | Open an issue in this repository |
| Help with your account, sign-in, or billing | support@pipeledger.ai, or <https://pipeledger.ai/support> |
| Help with your organization's data or results | The Communication Hub inside PipeLedger, or support@pipeledger.ai |
| To report a vulnerability | See [SECURITY.md](SECURITY.md) |

For email, PipeLedger targets an initial response within one business day.
Issues in this repository are answered as time allows and carry no response
commitment.

## Before you open an issue

This repository is public. Never include:

- a credential, token, client secret, or recovery code;
- financial records, account names, or customer and vendor names;
- your organization ID or a full error response that contains any of these.

A good issue includes the command you ran, the CLI version from
`pl --version`, your Node.js version, your operating system, and the error
`code` and `correlation_id` from the response. The correlation ID lets
PipeLedger find the request without you sharing its contents.

## What issues are for

Issues cover the tools and documentation in this repository. Questions about
a specific organization's data, access policy, or results cannot be answered
in public and will be redirected to support.
